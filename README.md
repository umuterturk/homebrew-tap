# homebrew-tap

Homebrew tap for [umuterturk](https://github.com/umuterturk)'s tools.

```sh
brew install umuterturk/tap/cxj
```

| formula | what it is                                                          |
| ------- | ------------------------------------------------------------------- |
| `cxj`   | [Stateless Java/Spring code intelligence CLI for coding agents](https://github.com/umuterturk/cxj) |

Formulas install GitHub Release binaries (no build step); each release of
[`cxj`](https://github.com/umuterturk/cxj) ships signed-digest assets for
macOS arm64/x86_64 and Linux arm64/x86_64, and the formula pins all four.
